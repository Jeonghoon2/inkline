# 백엔드 — 경험 점검표

보완할 경험(툴팁)을 만들 때 쓴다. 항목마다 **증거 키워드**를 기록(`~/My-History/*/YYYY-MM.md`)에서 찾고, 운영 배포까지 간 증거가 있으면 '있음', 로컬·설계만 있으면 '약함', 없으면 '없음'으로 본다.

| # | 항목 | 증거 키워드 (기록에서 찾을 말) | 공고 근거 |
| --- | --- | --- | --- |
| B1 | API 설계·계약 | API, 엔드포인트, POST/GET, 계약 검사, 하위 호환, 배포 순서, 문서화 | 토스플레이스 'API 계약', 점핏 'REST API 설계' |
| B2 | DB 모델링·마이그레이션 | 마이그레이션, Flyway, V1xx, 표 설계, 제약, jsonb, ALTER | 에이블리·토스 RDBMS |
| B3 | 트랜잭션·동시성·잠금 | 거래(트랜잭션), 잠금, advisory lock, 동시 실행, 경쟁, 유일 인덱스, 펜싱 | 토스플레이스 '동시성·중복 처리' |
| B4 | 성능 최적화(쿼리·메모리) | 실행 계획, 인덱스, 초 → 초, MB → MB, 나눠 읽기, 한 번만 읽기 | 토스뱅크 '성능 최적화' |
| B5 | 캐시 | 캐시, Redis, TTL, 무효화 | 토스뱅크·토스플레이스 우대 Redis |
| B6 | 메시지 큐·비동기 | Kafka, SQS, RabbitMQ, 큐, 소비자, 재시도 큐 | 토스 우대 Kafka |
| B7 | 대용량 트래픽·부하 시험 | rps, 처리량, 부하 시험, k6, p95, p99, 동시 사용자 | 토스뱅크·에이블리 '대용량 트래픽' |
| B8 | 테스트 | 테스트 N개, 통합 시험, PostgreSQL, 실패하는 시험 먼저, 회귀, E2E | 토스플레이스 '테스트와 리뷰' |
| B9 | 배포·CI/CD·무중단 | CI, 파이프라인, 작업 정의, 롤링, 되돌림, 무중단, 태그 | 토스뱅크 '운영 자동화' |
| B10 | 인프라 코드·클라우드 | Terraform, plan, ECS, RDS, S3, IAM, EventBridge | 공고 우대 IaC·클라우드 |
| B11 | 관측성 | 지표, 대시보드, 경보, 로그, 추적, CloudWatch, APM, p95 | 토스플레이스 '관측 데이터', SRE 네 신호 |
| B12 | 장애 대응·재발 방지 | 트러블슈팅, 원인, 재시작, 137, 복구, 재발 방지 | 토스뱅크·토스플레이스 공통 |
| B13 | 보안·개인정보 | 암호화, AES-GCM, HMAC, 감사 로그, 최소 권한, OWASP, 마스킹 | 금융·플랫폼 공고 공통 |
| B14 | 멱등성·재시도·타임아웃 | 멱등, 중복 요청, 체크포인트, 이어 하기, 시간 제한, keepalive | 토스플레이스 '타임아웃·재시도·부분 실패' |

## 판정 규칙
- 한 항목에 운영 수치가 있으면 '있음'. 숫자 없이 구현만 있으면 '약함'
- '약함'·'없음' 항목 중 공고 빈도가 높은 것부터 툴팁의 '부족한 경험'에 올린다
- '해보면 좋은 것'은 이미 있는 프로젝트에서 하루~이틀이면 되는 일로 적는다
