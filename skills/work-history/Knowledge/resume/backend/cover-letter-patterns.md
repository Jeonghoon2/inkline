# 백엔드 — 자기소개서 패턴

## 핵심 정리
- 토스뱅크 공고의 우대사항이 곧 자소서 문항이다: **참여 프로젝트·기여도·극복 과정 1개 이상**, **운영 중 문제와 시도·과정·결과**, **성장 목표**
- 직무 역량 문항 소재 = 트러블슈팅 한 건을 상황 → 원인 → 대안 비교 → 수정 → 효과 → 재발 방지로
- 지원 동기: 그 회사 공고의 '분산 환경 문제'(타임아웃·재시도·부분 실패 등) 중 내가 실제로 겪은 것과 잇는다
- 실패 경험: 내 판단이 원인이었던 장애 + 그 뒤 바꾼 규칙
