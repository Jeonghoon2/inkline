# 데이터 엔지니어 — 자기소개서 패턴

## 핵심 정리
- 면접 질문이 곧 자소서 소재다: **왜 이 구조인가**(다른 방법 대비), **어디까지 직접 했나**(팀 프로젝트면 내 몫을 분명히), **데이터를 어떻게 믿게 됐나**(정합성)
- 직무 역량: 파이프라인 한 건을 문제 → 설계 선택(대안 비교) → 운영 중 문제 → 수치로
- 실패 경험: 숫자와 형식만 보고 데이터 출처를 의심하지 않아 놓친 일 → 이후 바꾼 검증 습관
