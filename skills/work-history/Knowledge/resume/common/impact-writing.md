# 성과 한 줄 쓰기 (직무 공통)

## 핵심 정리
- 공식: **결과(수치) → 무엇을 → 어떻게**. 구글 XYZ("Y로 측정된 X를 Z로 이뤘다")를 한국어 어순으로 옮긴 것. Enhancv 는 영어식으로 "Action verb + technology + what you built/fixed + measurable result"
- 숫자 없는 줄은 '맡은 일'로 읽힌다(이력서 가이드 공통). 숫자는 **전 → 후 + 비율 + 측정 조건**
- 숫자가 없으면 **규모(scope)** 로 대신한다: 처리 건수, 학생 수, 테스트 수, 배포 횟수(DataCamp)
- 기술 이름은 '어떻게' 자리에 둔다. 가치(사용자·운영·비용)가 먼저 보이게
- 능력을 설명하지 말고 결과로 보여 준다. "능숙하게 작성함" 대신 규모와 결과(GeekNews 소개 글)
- 흔한 경험보다 **나만 한 문제 해결** — 원인을 찾은 과정, 다른 방법과 비교한 근거
- 직무마다 독자가 찾는 숫자가 다르다(각 직무의 `what-hiring-looks-for.md`)

## 직무별 숫자 예
| 직무 | 먼저 볼 숫자 |
| --- | --- |
| 백엔드 | 응답 시간(초·p95), 메모리, 장애 시간, 테스트 수, 배포 무중단·실패 0 |
| 프론트엔드 | 번들·시작 코드 크기, 레이아웃 이동(px·CLS), 화면 상태 점검 수, 결함 재현 줄 수 |
| 데이터 엔지니어 | 처리 행 수, 파일 수, 메모리 피크, 건수 일치(정합성), 조회 시간, 보관 기간 |
| AI 엔지니어 | 차단·오류 문항 수 전 → 후, 토큰·비용, 응답 지연(초), QA 통과율, 감사 결과 |

## 하기 / 하지 않기
- 하기: 한 줄에 하나, 명사형 끝(…단축, …제거, …설계)
- 하기: 측정하지 않은 말('무중단', '대폭')은 쓰지 않거나 측정 근거를 붙인다
- 하지 않기: "~를 담당", "~에 참여" 같은 수동 표현만으로 끝내기
- 하지 않기: AI 로 문장을 부풀리기 — Enhancv 도 "never let it invent or inflate experience" 라고 한다
