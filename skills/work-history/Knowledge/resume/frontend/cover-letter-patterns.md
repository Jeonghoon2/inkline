# 프론트엔드 — 자기소개서 패턴

## 핵심 정리
- 엘리스 공고가 직접 요구: 지원 동기, **숫자로 표현한 성과**, 기술 스택이 아니라 **실제 개발 경험과 성장 과정**
- 직무 역량 소재: 사용자 불편을 어떻게 발견했고(실서버 데이터 재현·프레임 기록), 무엇을 기준으로 고쳤으며(지표), 회귀를 어떻게 막았는지(테스트·점검 수)
- 협업 소재: 디자인 규칙(디자인 시스템) 안에서 화면을 맞춘 일, 서버 쪽과 계약을 맞춘 일
- 2026년 흐름: AI 도구로 생산성을 올린 경험을 묻는 공고가 늘었다(엘리스) — 실제로 쓴 방식과 품질을 지킨 장치(검토·테스트)를 함께
