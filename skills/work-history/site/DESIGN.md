# DESIGN.md — My History (Ink & Highlighter)

타임라인 페이지(index.html)의 디자인 규칙. 값은 `src/styles/base.css` 의 `:root` 토큰이 원본이다 — 여기에는 **어느 토큰을 언제 쓰는지와 그 이유**만 적는다. 화면을 고치면 이 문서도 같이 고친다. (이 문서·`src/` 는 work-history 스킬의 `site/` 에 있다 — 기록 폴더 ~/My-History 에는 데이터만 있다)

## Overview
종이 위에 잉크로 쓴 작업 일지에 형광펜을 친 느낌. 읽는 화면이지 대시보드가 아니다 — 장식보다 글과 숫자가 먼저 보인다.
레퍼런스(2026-10-13): 목록은 Myna UI Changelog(날짜 칸) + Filllo Activity Timeline(종류 탭), 상세는 Studio Design Changelog Concept(기사형) + Headway(형광펜), 개요는 Yow Journal Dashboard(활동 지도), 이력서는 원티드 이력서 예시(1단 문서, 2026-10-17 교체 — 그 전엔 Studio Design CV Concept 신문형 2단).

## Colors
- **바탕 `--bg` · 칸 `--card` · 선 `--line` · 옅은 면 `--soft`**: 바탕은 순백이 아닌 종이색, 카드만 흰색이라 그림자 없이도 칸이 떠 보인다. `--soft` 는 눌리지 않은 탭·단추 바탕, 번호 칸
- **잉크 `--fg` · 본문 보조 `--sub` · 흐린 글 `--muted`**: 제목·숫자는 `--fg`, 카드 요약·목록 본문은 `--sub`, 날짜·건수·라벨은 `--muted`. `--muted` 도 바탕 위 4.5:1 을 넘게 잡았다 — 더 옅게 내리지 않는다
- **형광펜 `--hl` (+ 옅은 `--hl-soft`)**: 강조색은 이것 하나. 개념 형광펜(`mark.cc`), 꼬리 질문 답의 왼쪽 띠에만 쓴다(이력서에는 쓰지 않는다). 글자색이 아니라 **글자 아래 45% 부터 칠하는 면**이다
- **링크 `--accent`**: 누를 수 있는 글자(프로젝트 링크, '더 보기')에만. 버튼 면 색으로 쓰지 않는다
- **종류 `--t-feat` 기능 · `--t-ship` 배포 · `--t-fix` 수정 · `--t-doc` 문서 · `--t-perf` 성능 · `--t-trouble` 트러블슈팅**: 라벨 글자색 + 같은 색 12% 면(`.b` 가 `--t` 로 받는다)과 목록 점에만. 카드 테두리·제목을 물들이지 않는다. 색만으로 가르지 않게 라벨에 늘 이름을 쓴다
- **활동 지도 `--heat0`~`--heat4`**: 잉크 한 색의 농도 5단계(0건 · 1~2 · 3~5 · 6~9 · 10+). 초록 잔디처럼 브랜드색을 쓰지 않는다
- **어두운 테마**: 같은 이름을 `:root[data-theme="dark"]` 에서 다시 정의한다. 새 색을 넣으면 두 곳 다 넣는다. 테마는 머리말 오른쪽 ☾/☀ 단추로 바꾸고 브라우저에 기억한다(`localStorage` 의 `mh-theme`). 고른 적이 없으면 처음 열 때 시스템 설정을 따른다 — `template.html` 의 head 스크립트가 글자보다 먼저 정해 깜빡이지 않게 한다. `prefers-color-scheme` 를 CSS 에 다시 쓰지 않는다(단추와 어긋난다). 형광펜은 어두운 바탕에서 반투명 노랑
- **쇼츠 띠(`.d-shorts`)** 만 테마와 상관없이 검은 면 — 영상이 검은 바탕이라 이어 보이게

## Typography
- 본문·제목: IBM Plex Sans KR (`--sans`). 숫자·날짜·버전 묶음 강조: IBM Plex Mono (`--mono`)
- **한글이 섞인 라벨에는 `--mono` 를 쓰지 않는다** — Plex Mono 에 한글이 없어 다른 글꼴로 대신 그려지고, 띄어쓰기가 고정폭 공백이라 벌어져 보인다. 한글 + 숫자 라벨은 산세리프에 `.num`(같은 폭 숫자)
- 크기: 페이지 제목 34 · 상세 제목 32(휴대폰 26) · 섹션 21 · 카드 제목 17 · 본문 15(상세 16, 줄간격 1.75) · 라벨 12~13
- 자간: 24px 이상 제목만 -0.02~-0.03em. 영문 대문자 머리말(MY HISTORY)·작은 라벨은 +0.06em

## Layout
- 본문 폭 최대 1180px, 좌우 24px(휴대폰 16px). 칸 사이 16, 카드 사이 12, 구역 사이 28
- 줄 배치는 `flex-wrap` + `flex: N 1 기준폭; min-width: 0` — 좁아지면 아래로 쌓인다. 고정 12칸 그리드를 쓰지 않는다(휴대폰에서 겹친다)
- 목록: 왼쪽 날짜 칸 110px(날짜 mono 20 · 요일 · 건수) + 세로선 + 카드. 휴대폰에서는 날짜 칸이 카드 위로 간다
- 상세 창: 본문(최대 760) + 오른쪽 칸(240~). 오른쪽 칸에는 날짜·프로젝트·이 기록의 개념·같은 날 기록만

## Icons
- 이모지·기호 글자(▶ ☀ × ⏳)를 아이콘으로 쓰지 않는다 — 글꼴·OS 마다 모양과 굵기가 다르다. `common.js` 의 `icon(이름)` 이 Lucide(ISC) 선 그림을 SVG 로 넣는다(play · x · sun · moon · loader)
- 크기·색은 둘레 글자를 따른다(1em, `currentColor`, 선 2px). 재생 삼각형만 면으로 채운다. 새 아이콘은 Lucide 의 path 를 `ICON` 에 옮겨 쓴다 — 아이콘 묶음을 내려받아 붙이지 않는다. 보완할 경험 단추는 lightbulb(`bulb`)
- 아이콘만 있는 단추에는 `aria-label`, 뜻을 지닌 아이콘 글자에는 `role="img"` + `aria-label`, 나머지는 `aria-hidden`

## Scroll
- 상세 창은 창 틀이 멈춰 있고 안(`.detail-body`)만 스크롤한다 — 닫기 단추가 늘 오른쪽 위에 있고, 열린 동안 뒤 목록(`html`)은 스크롤하지 않는다(`overscroll-behavior: contain` 으로 끝에 닿아도 뒤로 넘기지 않는다)
- 스크롤바는 얇게(`scrollbar-width: thin`), 잉크 22%(올리면 38%) · 길은 투명. 브랜드색으로 칠하지 않는다
- 창 맨 위 3px 잉크 띠가 읽은 만큼 차오른다. CSS 스크롤 애니메이션(`animation-timeline: scroll()`)만 쓴다 — 스크롤 이벤트에 스크립트를 걸지 않는다
- 기록을 바꿔 열면(같은 날 다른 기록) 맨 위로 돌아간다

## Elevation & Depth
- 그림자를 쓰지 않는다. 칸은 흰 카드 + 1px 선으로 가른다
- 예외: 눌린 탭의 1px 그림자, 말풍선(#tip)·보완할 경험 칸(`.gap-panel`)·상세 창처럼 다른 층에 뜨는 것

## Shapes
- 크기가 커질수록 모서리도 커진다: 라벨·칩 알약(999) · 입력·탭·작은 단추 8 · 목록 줄 12 · 카드 14 · 상세 창·쇼츠 띠 16~18 · 이력서 종이 12 · 이력서 칩·아이콘 칸 8~10

## Components
- **종류 라벨 `.b`**: `style="--t:var(--t-…)"` 로 색만 넘긴다. 높이 22, 글자 12 굵게
- **카드 `.item`**: 라벨 · 프로젝트 · 오른쪽에 '개념 N · ▶ 쇼츠 M' / 제목 / 요약 두 줄(넘치면 자름). 누르면 상세. 마우스·포커스 때 선만 잉크색으로
- **압축 줄 `.row`**: 제목 한 줄(말줄임) · 프로젝트 · 라벨. 높이 50
- **종류 탭**: 건수를 늘 붙인다(다른 거르기를 반영한 수). 고른 탭은 잉크 면 + 바탕색 글자
- **형광펜 `mark.cc`**: 기록의 `==글자|개념==`. 마우스·포커스에 원리 말풍선. 한 문단에 너무 많이 칠하지 않는다(기록당 1~4곳)
- **해결 과정 `ol.steps`**: 번호를 30px 둥근 네모(mono)에 넣는다. 다른 번호 목록도 같은 모양. 번호는 `li` 왼쪽 여백(44px)에 `position:absolute` 로 띄우고 `li` 자체는 보통 블록으로 둔다
- **글자가 흐르는 칸에 flex·grid 를 쓰지 않는다** — 기록 본문처럼 굵은 글자·형광펜·글자가 섞인 `li`·`p` 를 flex 로 두면 조각마다 칸이 되어 나란히 갈라진다('원인 찾기'가 세로로 접히고 형광펜이 섬처럼 떨어졌다, 2026-10-13). flex 는 배지·버튼처럼 정해진 요소만 담는 줄에 쓴다

  - 인쇄: A4(여백 16·14mm), 머리말·탭·단추·직무 칩·보완할 경험을 빼고(고른 직무 이력서만 찍힌다) 종이 테두리 없이, 밝은 색으로 고정하고 화면 크기를 0.8 배로 줄여 쪽에 맞춘다. 구역 사이 40 · 소개 위 24 · 프로젝트 사이 24 · 기술 줄 사이 6 으로 줄여 직무 이력서가 A4 2쪽에 든다(2026-10-17). 회사 머리·기술 줄·성과 한 줄은 쪽 사이에서 끊지 않고, 새 꼴 프로젝트는 성과 줄 사이에서만 넘긴다(통째로 넘기면 쪽 끝이 비어 3쪽이 됐다). 제목·머리 줄·소제목 바로 뒤에서는 넘기지 않는다

- **쇼츠 플레이어 `.vp`** (`shorts.js` 의 `player()`): 브라우저 기본 조작판을 쓰지 않는다 — OS·브라우저마다 모양이 달라 검은 쇼츠 띠와 어긋난다. 세로 영상이라 폭이 좁아(띠 400px 높이 → 폭 225px) 위 줄에 재생 위치 막대, 아래 줄에 재생 · 시간 · 속도(1→1.25→1.5→2×) · 소리 · 전체 화면. 재생/멈춤/다시 보기는 아래 줄 첫 단추이고 영상 아무 데나 눌러도 된다. **가운데에 단추를 두지 않는다** — 멈춘 장면의 그림·글자를 가렸다(2026-10-13). 누르면 가운데에 아이콘이 0.6초 떴다 사라진다. 재생 중 1.8초 가만있으면 조작판과 커서가 숨는다(키보드 포커스가 안에 있으면 남는다). 하나를 틀면 다른 영상은 멈춘다. 키: Space·K · ← → 5초 · M · F. 테마와 상관없이 어두운 색(영상 위라서), 아래 그늘만 그라데이션 예외
- **다음 편·이전 편 `.sh-next`**: 쇼츠의 후속 편(선행·심화, concept-shorts 스킬 '후속 영상')을 잇는 알약 단추. 띠 글 아래와 꼬리 질문 플레이어 아래에 둔다. 누르면 같은 플레이어에서 영상만 바꾼다(새 창·새 플레이어를 띄우지 않는다). 만드는 중이면 도는 원 + '만드는 중', 아직 없으면 단추를 두지 않는다
- **아직 안 채운 칸 `[대괄호]`**: 노란 면 + 갈색 글자. 인쇄 때는 면을 뺀다

## Motion
움직임은 손에 답할 때만 짧게(0.12~0.5초) 쓴다. 저절로 반복되는 장식 움직임은 없다(예외: 쇼츠 만드는 중의 도는 원). 값은 `src/styles/motion.css` 한 파일에 모여 있다.
- **누름**: 단추는 누르는 동안 96% 로 줄어든다. 카드는 올리면 2px 떠오르고 목록 점이 커진다 — 그림자는 여전히 쓰지 않는다
- **스크롤로 들어옴**: 카드·개요 칸이 아래에서 18px 떠오르며 나타나고, 형광펜은 글이 들어올 때 왼쪽부터 그어진다(상세 창에서는 읽어 내려가는 대로). CSS 스크롤 애니메이션(`animation-timeline: view()`)만 쓴다
- **화면 전환(View Transitions, `vt()`)**: 종류·보기·위 탭·이력서 직무 칩을 바꾸면 고른 면이 다음 단추로 미끄러지고, 카드마다 이름(`e<번호>`)이 있어 거르면 남은 카드가 제자리로 움직인다. 검색 입력은 글자마다 바뀌어 전환을 걸지 않는다. 숨은 탭(`document.hidden`)에서는 브라우저가 전환을 거절해 오류만 남으므로 바로 바꾼다
- **테마**: 단추 가운데서 원이 퍼지며 새 색이 덮는다(0.5초). 그동안 다른 전환 이름은 끈다(`.vt-theme`)
- **상세 창**: 아래에서 떠오르며 열리고 배경이 서서히 어두워진다(`@starting-style`). 이전·다음 기록(단추, ← → 키)으로 바꾸면 본문만 새로 들어온다. 꼬리 질문 답은 높이가 펼쳐지고 꺾쇠가 돈다
- **첫 화면 숫자**: 0 에서 제 값까지 0.7초 동안 올라간다(처음 한 번만)
- **첫 화면 차례**: 머리말 → 개요 칸 → 거르기가 0.06초 간격으로 떠오르고, 활동 지도 칸은 왼쪽 위부터 물결처럼 돋는다(`body.intro`, 1.6초 뒤 뗀다 — 다시 그려도 되풀이하지 않게)
- **타임라인 세로선**: 날짜 칸이 화면을 지나는 만큼 잉크(`--heat3`)로 그어진다. 압축 보기에는 선이 없다
- **형광펜에 올리기**: 칠한 면이 글자 전체 높이로 차오른다. 형광펜 크기는 등록한 변수(`--hlx` 가로 · `--hly` 세로, base.css)라 그어짐과 차오름이 따로 움직인다. (이력서에는 형광펜이 없다)
- **페이지 읽은 만큼 띠·맨 위로 단추**: 화면 맨 위 3px 잉크 띠, 300px 넘게 내리면 오른쪽 아래에 맨 위로 단추가 떠오른다. 스크롤을 따라갈 뿐이라 '동작 줄이기'에서도 둔다(base.css)
- **작은 반응**: 새 거르기 칩·테마 아이콘은 튀어나오듯, 말풍선과 보완할 경험 칸은 4px 올라오며 나타난다(전구는 올리면 살짝 기운다). 단추 속 화살표·재생 아이콘은 가리키는 쪽으로 2px 움직인다. 검색 칸은 누르면 300px 로 넓어진다(넓은 화면)
- **인쇄**: `motion.css` 는 `screen` 에만 — 스크롤 애니메이션이 인쇄에서 0 에 멈춰 이력서 구역이 투명하게 찍히지 않게
- **눌러서 거르기**: 활동 지도에서 기록 있는 날 칸을 누르면 그날만 본다('날짜: M.D ×' 칩, 다시 누르면 풀림). `/` 키로 검색 칸
- **`prefers-reduced-motion`**: `motion.css` 전체가 `no-preference` 안에 있어 통째로 꺼지고, 스크립트(`calm()`)도 전환·숫자 올라가기를 건너뛴다. 기능(거르기·이전·다음)은 그대로다
- 새 움직임은 `motion.css` 에 넣는다 — 다른 조각 파일에 `transition`·`animation` 을 흩어 두지 않는다(읽은 만큼 띠·도는 원은 기능이라 제자리에 둔다)

## 하지 않는 것
- 그라데이션 면, 왼쪽 굵은 색 띠 카드, 이모지 아이콘, 종류마다 카드 전체를 물들이기
- 보라·파랑 브랜드 그라데이션 같은 'AI 대시보드' 느낌
- 기록마다 같은 방식으로 뽑을 수 없는 숫자 칸(예: 상세 창 '핵심 수치 3칸') — 시안에는 있었지만 데이터가 일정하지 않아 뺐다
